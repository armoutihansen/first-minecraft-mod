# Agent guidance

This repository contains **Die Zauberschmiede**, a small Minecraft Bedrock Survival world project for a parent and child.

Keep the first playable version simple, understandable, and compatible with ordinary Bedrock clients on iPhone and an Amazon Kids tablet. Do not introduce experimental creator features unless a later issue explicitly changes that decision.

Before changing product behavior, read `CONTEXT.md` and relevant records under `docs/adr/`.

## Agent skills

### Issue tracker

Work and PRDs are tracked in this repository's GitHub Issues; external pull requests are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The repository uses the five standard triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` at the root and architectural decisions under `docs/adr/`. See `docs/agents/domain.md`.
