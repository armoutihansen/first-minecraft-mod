# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read the architectural decision records under `docs/adr/` that affect the area being changed.
- If either source is absent, proceed without blocking.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issue titles, requirements, test names, and implementation notes. Avoid introducing synonyms for established project concepts.

## Architectural decisions

If proposed work contradicts an existing ADR, identify the conflict explicitly instead of silently overriding it. Add future decisions under `docs/adr/` using sequential four-digit numbers.
